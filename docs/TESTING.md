# 回歸測試清單

## 自動檢查

在 `canva-worker/` 執行：

```bash
npm test
```

根目錄前端檔案不需編譯。提交前可用 `node --check` 檢查四個 JavaScript 檔案與 Worker。

## 桌面版

- 首次開啟沒有資料時顯示空白提示。
- 日期左右按鈕、日曆與回到今天正常。
- 快速新增能帶入時間、主題、書名、Canva 與比例。
- 主題與書名可輸入搜尋，也能建立新項目。
- 編輯器工具列換行、粗體、斜體、底線、刪除線、螢光與顏色正常。
- 編輯器側欄只有外層捲軸；工具列、輸入框與刪除按鈕不水平溢出。
- 專注編輯能進入與離開，Esc 可退出。
- Canva 預覽預設不攔截頁面滾動，按「操作 Canva」後才可操作 iframe。
- GitHub 同步成功後遠端 `database.js` 有新 commit。
- JSON 匯出與匯入可恢復資料。

## Canva 多頁

- 未設定 Worker 時，點多頁解析會展開設定欄。
- 長網址與 `canva.link` 短網址都能解析。
- 頁數、縮圖與頁碼順序正確。
- 短網址解析完成後，左側以圖片輪播顯示，不建立會被 Canva 擋下的 iframe。
- 單頁下載檔名為 `日期-書名-第N頁.png`。
- 下載全部會產生一個 ZIP，ZIP 內每個圖片檔名的頁碼不同。
- 失效或非公開連結顯示錯誤，不會破壞其他功能。

## 手機版（767px 以下）

- 只顯示「日視圖」與「預覽」兩個分頁。
- 不顯示編輯器，符合目前產品需求。
- 頁面無水平捲動。
- 選取貼文後自動切到預覽。
- Canva iframe 保持鎖定，不會攔截上下捲動。
